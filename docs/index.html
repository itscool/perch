Quiet controls for noisy problems.

Perch keeps the important state visible, gives risky actions a clear path, and stays out of the way when everything is ready.

Sleep

Lid-aware keep awake

Keep a Mac awake when it is closed on power, with a supervised timeout and an activity log when normal sleep should resume.

Displays

See the route

Build three display presets by wiring numbered computer ports to physical monitor inputs, then switch with an honest result.

Input

Make keyboards yours

Separate built-in and external keyboard controls, direct function keys, modifier swaps, navigation keys, and device-aware setup.

Safety

A real emergency brake

Preview recognized local agents, test the kill shortcut safely, and keep the action close without pretending it is containment.
