# Perch 2.0.283 — What’s new

- **Presets count as active when your screens say so:** many monitors never report which input they are showing, so a preset could look like it had failed while every screen was exactly where you asked. Perch now accepts a screen when the Mac that preset chose, and only that Mac, can see it.
- **Keyboard and mouse sharing follows:** sharing waits for an active preset, so presets that quietly looked failed were holding it back.
- **Check and tell, never install:** when another Mac on your desk is newer, Perch looks for the published release and tells you it is available. Installing stays yours.

Perch requires Apple silicon and macOS 26 or later. See Settings → Updates → Release history for the complete history of Perch releases.
