# Perch 2.0.278 — What’s new

- **Switching a screen between Macs:** Perch now checks whether a screen is reachable the same way it sends the command, so a switch is no longer reported as failed for a screen it can actually reach.
- **Driving the other Mac:** when none of your screens are in the preset you switch to, your keyboard and mouse drive the Mac that is on screen instead of sharing being refused.
- **Macs keep each other current:** a Mac that has updated tells the others as soon as it reaches them, and one that is behind looks for the release by itself.
- **When something goes wrong:** the Macs share their reasoning, so one Mac's log explains the whole desk, including why a screen could not be switched or handed to another Mac.

Perch requires Apple silicon and macOS 26 or later. See Settings → Updates → Release history for the complete history of Perch releases.
