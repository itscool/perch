# Perch 2.0.96

- Fix local builds that could leave Sparkle missing and prevent Perch from launching.
- Improve setup and permission recovery, settings navigation, validation and return from child dialogs.
- Show pending lid-helper maintenance as needing attention and explain what active protection can confirm.

This is a prepared release candidate. Physical multi-Mac, monitor and lid acceptance
is still required before release; this draft is not a publication record.
