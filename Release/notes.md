# Perch 2.0.311 — What’s new

- **Your Macs stay in step.** A fault filled the connection between the Macs, delaying screen switches, copies and the pointer, and using CPU. It is fixed.
- **The desk is read from the screens.** Each Mac knows which screens it is showing, so the active preset is the one your screens actually show, and a switch is confirmed as soon as the picture moves.
- **⌃⌥⌘V pastes the newest copy from any Mac** straight into the app you are in, bringing it over first when it is on another Mac. A folder holding a broken link now comes over too.
- **Perch controls sleep you turned off yourself.** If sleep was disabled outside Perch, Perch takes it over instead of refusing, and the menu says who set it. Restart and updates work with the lid closed. The lid helper updates once, asking for your password.
- **Versions read as from → to,** and Perch offers only updates that can really happen.
- Shorter, plainer menu tooltips, and the disk line starts with the disk’s size.

Every Mac on the desk needs this version.

Perch requires Apple silicon and macOS 26 or later. See Settings → Updates → Release history for the complete history of Perch releases.
